# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities on Facebook, WhatsApp, or X, or copy a direct link

## Sharing an activity

Use the sharing buttons at the bottom of any activity card. Social sharing opens
the chosen service in a new tab, where you can review your post before sending it.
No teacher login is needed.

Choose **Copy link** to send an activity through another app. If your browser
cannot copy automatically, a selected link appears for you to copy manually.
Opening a shared link scrolls to and highlights that activity. Shared messages
include only the activity name, description, and link, not student information.
